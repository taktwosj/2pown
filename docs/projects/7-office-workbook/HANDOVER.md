# 고객관리 엑셀 인수인계서

> 이 문서는 고객관리 엑셀 프로젝트의 유일한 인수인계 기준 문서다.
> 오래된 작업은 Git history로 확인한다.
> 작업 마무리 시 이 문서의 "최근 작업"을 최근 7일만 남기고 갱신한다.

## 1. 프로젝트 목적

통합관리.xlsm — 대출 고객 데이터 관리, 상품시트 수당/금리 계산, VBA 자동채움.
H시트가 고객 데이터 메인이며, 텔레그램 봇/daily_sync/CRM과 연동된다.

## 3. 정본 / 로컬 / 런타임 구분

| 구분 | 위치 | 역할 |
|------|------|------|

## 4. 핵심 파일

| 파일/시트 | 역할 |
|----------|------|
| `통합관리.xlsm` H시트 | 고객 데이터 메인 (접수/상담/기표/상환 전체) |
| `통합관리.xlsm` 상품시트 | 은행별 금리/수당률/보너스 |
| VBA 모듈 | H시트 자동채움, 수당 계산 |

**연동 관계**:
- 대출상품/금리/수당/은행조건은 **bankly MCP 서버가 유일한 정본**이다. 상품시트 변경 시 MCP를 최우선으로 조회하고, MCP 값과 다른 곳의 값이 다르면 MCP가 맞다.
- 상품시트/금리 변경 시: `금융조견.html` (BANKLY) + `bot.py` 상품 분류 로직 함께 확인
- H시트 데이터: `daily_sync.py`가 CSV로 변환 → Cafe24 서버 → ivwith DB 동기화
- 텔레그램 봇이 Excel COM으로 직접 읽기/쓰기 (admin접수, 엑셀 고객입력 메뉴)
- 전체 연동 구조: `C:\2POW\docs\SYSTEM_MAP.md` 참조

## 5. 현재 상태

LIVE (운영 중). 집/사무실/외부 모두 `C:\2POW\고객관리\` 기준.

## 6. 현재 리스크

- Git 관리 아님 — PC 장애 시 서버 백업만 복구 수단
- 상품시트와 MCP 서버/금융조견.html 간 데이터 동기화가 수동

## 7. 최근 검증

- daily_sync 엑셀 읽기 정상
- 텔레그램 봇 Excel COM 정상
- H시트 상태 조회가 101행 고정이 아니라 마지막 이름행까지 읽도록 보강

## 8. 최근 작업

- `daily_sync.py`, `ivwith_report.py`의 H시트 범위를 마지막 이름행 기준으로 확장
- H시트 E열 고객상태 판단표와 고객현황 리포트 상태판정을 `ivwith/customer_status_rules.py`로 공통화

## 9. 업데이트 규칙

- 작업 전 이 문서를 먼저 읽는다.
- 작업 후 "최근 작업"에 **변경 / 검증 / 리스크**만 기록한다.
- 최근 7일만 남기고 오래된 항목은 제거한다. 과거 이력은 Git history로 확인한다.
- 상품시트/금리 변경 시 bankly MCP 서버 + 금융조견.html + bot.py 상품 분류 동시 확인한다.
- 대용량 원본 CSV/XLSX는 명시 요청 없이 수정하지 않는다.
