# Repo Blueprints

이 폴더는 `1POW`에서 새 Git 저장소를 만들 때 참고하는 블루프린트를 모아둔 곳이다.

실제 정본 저장소가 아니라, 아래 목적의 설계 샘플이다.

- 어떤 문서를 어느 저장소로 분리할지 고정
- 새 repo 생성 시 기본 폴더 구조를 빠르게 복사
- 집/사무실/서버 사이의 문서 기준 혼선을 줄임
- `repo` 없는 프로젝트의 임시 문서 구조를 표준화

현재 포함된 블루프린트:

- `1pow-ops-docs/`

이 블루프린트는 아래 문서를 위한 신규 Git 저장소 스캐폴드다.

- `START.md`
- `CLAUDE.md`
- `GPT.md`
- `docs/projects/<project-id>/...`

주의:

- 외부 독립 저장소의 handover나 규칙 문서를 여기로 다시 미러링하지 않는다.
- 이 블루프린트는 외부 별도 repo 자체를 대체하지 않는다.
- 시크릿, 대용량 결과물, 백업 파일은 여기에 넣지 않는다.
